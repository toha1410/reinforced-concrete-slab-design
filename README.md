# Reinforced Concrete Floor Slab Design

## Project Overview
This course project focuses on the structural design of a reinforced concrete floor system with dimensions of 24 m × 18 m. Plastic moment redistribution was applied to continuous slabs and secondary beams, while elastic theory was used for the main beams.

## Project Details
- **Project Type:** Civil Engineering Course Project
- **Field:** Structural Engineering
- **Design Focus:** Reinforced concrete slab and beam design
- **Methods:** Plastic moment redistribution and elastic theory
